# Programação em Python - Módulo de Aprendizado

Estrutura organizada de módulos Python cobrindo conceitos fundamentais de programação.

## 📁 Estrutura do Projeto

```
programacao-python/
├── 01_tipos_e_conversoes/      # Conversão de tipos e declarações
├── 02_operacoes_aritmeticas/   # Operações matemáticas básicas
├── 03_entrada_e_saida/         # Input/Output do usuário
├── 04_calculos_comerciais/     # Aplicações práticas (compras, totais)
├── 05_operacoes_matematicas/   # Operações avançadas com Math
├── tests/                       # Testes dos módulos
├── utils/                       # Utilitários compartilhados
├── README.md
└── requirements.txt
```

## 🎯 Módulos

### 1. Tipos e Conversões
- Conversão explícita entre tipos (str, int, float)
- Verificação de tipos
- Boas práticas de declaração

### 2. Operações Aritméticas
- Operações matemáticas simples
- Manipulação de números
- Casting de valores

### 3. Entrada e Saída
- Captura de dados do usuário (input)
- Formatação de saída (print)
- Validação de entrada

### 4. Cálculos Comerciais
- Cálculo de valor total
- Multiplicação com variáveis
- Aplicações do mundo real

### 5. Operações Matemáticas
- Potência e expoentes
- Expoentes fracionários
- Uso do módulo math

## 🚀 Como Usar

Cada módulo contém exemplos de uso. Para executar um exemplo:

```bash
python 01_tipos_e_conversoes/exemplo_uso.py
python 03_entrada_e_saida/exemplo_uso.py
```

## 📝 Notas

- Todos os módulos seguem PEP 8
- Cada função está documentada com docstring
- Exemplos práticos incluídos em cada módulo
